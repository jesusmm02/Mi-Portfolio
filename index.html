Pet Clinic - Sistema Veterinario 🐾🏥

Trabajo de Fin de Grado (DAW): Plataforma Full-Stack estructurada bajo los patrones de diseño MVC (Modelo-Vista-Controlador) y DAO para garantizar una arquitectura escalable y una separación limpia de la lógica de negocio. 📐🏗️

Arquitectura y Tecnologías Backend: 🛠️
☕ Core: Desarrollado sobre Java EE 7 utilizando Servlets para el enrutamiento y manejo de peticiones HTTP.
🗄️ Persistencia: Gestión relacional con MySQL 8 y acceso a datos mediante el ORM Hibernate JPA.
⚙️ Herramientas: Construcción del proyecto y dependencias gestionadas con Maven, integrando librerías como Gson y Commons BeanUtils.

Sistema de roles: 👥 Autenticación con portales dedicados para clientes (gestión de mascotas y citas) y veterinarios (historiales clínicos y agenda dinámica).

Reproductor Web 🎵

Desarrollo de un reproductor de audio web totalmente funcional e interactivo. El proyecto cuenta con un sistema completo de controles que incluye: reproducción aleatoria (shuffle), navegación entre pistas (anterior, play/pause, siguiente), y función de repetición.

IberGasoil ⛽

Aplicación desarrollada en Angular diseñada para ayudar a los usuarios a encontrar las estaciones de servicio más económicas en tiempo real.

La web permite realizar búsquedas precisas filtrando por provincia y municipio. Además, el usuario puede seleccionar el tipo de carburante y ordenar los resultados de menor a mayor precio.

💡 Detalle técnico: La interfaz está programada para manejar dinámicamente la información, ocultando los precios de los combustibles que no estén disponibles en ciertas estaciones.

Estudio de IA PRO 🚀🎨

Aplicación web interactiva alojada en Hugging Face Spaces que permite a los usuarios generar imágenes personalizadas utilizando modelos de Inteligencia Artificial.

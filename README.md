# 👨‍💻 Portfolio Personal | Jesús Melara Martín

¡Bienvenido al código fuente de mi portfolio web! 🚀 

Este espacio interactivo está diseñado para mostrar mi trayectoria, formación y los proyectos más destacados que he desarrollado como profesional **Full-Stack** y **Técnico de Sistemas**. Está construido con un enfoque en la experiencia de usuario (UX/UI), utilizando un diseño *Dark Modern*, efectos de *Glassmorphism* y animaciones fluidas. ✨

## 🛠️ Tecnologías Utilizadas

La interfaz de este portfolio ha sido desarrollada desde cero utilizando tecnologías web modernas para garantizar que sea 100% responsiva y rápida:

* **HTML5 & CSS3** (Diseño fluido, variables CSS y animaciones `@keyframes`).
* **Vanilla JavaScript** (Efectos de escritura dinámica y manipulación del DOM).
* **Bootstrap 5** (Sistema avanzado de cuadrículas y componentes modales).

## 📂 Proyectos Destacados en la Galería

Dentro del portfolio podrás explorar en detalle aplicaciones reales desarrolladas en diversas tecnologías:

1.  🔴 **Pokédex Interactiva:** Consumo de API REST con Vanilla JS.
2.  🎮 **GameShop E-commerce:** Single Page Application (SPA) con Angular y Tailwind.
3.  🎵 **Reproductor Web:** Gestión avanzada de la API de Audio de HTML5.

5.  ⛽ **IberGasoil:** Buscador de gasolineras dinámico con Angular y filtrado de datos.
